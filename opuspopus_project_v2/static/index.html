Single-agent pipeline

  1. Ingest: trials from ClinicalTrials.gov API v2 (free-text criteria split into individual rules) and synthetic patient notes.
  2. Understand patient: the LLM extracts structured facts (age, sex, diagnoses, labs, meds, history).
  3. Retrieve (RAG): trials are ranked by relevance to the patient.
  4. Rule engine: Python enforces age, sex and pregnancy rules deterministically.
  5. Reason: the LLM judges each criterion as MET / NOT MET / UNKNOWN, with quoted evidence.
  6. Decide: any failed inclusion or triggered exclusion → Not eligible; missing data → Needs review; otherwise Eligible.
  7. Explain: a plain-English rationale for the clinical coordinator.

Privacy: synthetic patients only. Safety: “Needs review” keeps a human in the loop.
